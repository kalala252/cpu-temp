# CPUTemp

macOSのメニューバーに温度を表示するアプリです。CPUに分類したセンサーのうち、最も高い温度を表示します。アイコンをクリックすると、GPUやバッテリーなど、取得できたほかのセンサーも確認できます。

CPUのセンサーが見つからない場合は、メニューバーに`--℃`、詳細画面に「取得不可」と表示します。GPUやバッテリーの温度で代用しません。

## 動作環境とビルド環境

実行対象はmacOS 13以降です。センサーの取得は非公開インターフェイスに依存するため、機種やOSのバージョンによって取得できる情報が変わります。Intel Macでの動作は未検証です。SMCの読み取り対象は、Apple Silicon向けのキーに絞っています。

ビルドにはmacOS 26 SDKを含むXcode 26以降、または対応するCommand Line Toolsが必要です。macOS 26の描画APIを使用しているため、古いSDKではコンパイルできません。実行時にはOSのバージョンを確認し、macOS 13〜15では従来の描画に切り替えます。

```bash
git clone https://github.com/kalala252/cpu-temp.git
cd cpu-temp
./build_app.sh
open dist/CPUTemp.app
```

スクリプトはReleaseビルドを行い、`dist/CPUTemp.app`を作成します。アプリはメニューバーに常駐し、Dockには表示しません。

ログイン時に起動したい場合は、「システム設定 → 一般 → ログイン項目」で作成したアプリを追加してください。終了は、温度をクリックして開く画面のボタンから行えます。

macOS 26.6.2のApple Silicon端末で、ビルドと診断コマンドによる温度の取得を確認しています。macOS 13〜15やIntel Macでの実機確認は行っていません。

## 表示する温度

約2秒ごとにセンサーを読み直します。取得値のうち、1〜130℃の範囲外にあるものと、名前に`tcal`を含むものは表示対象から外しています。

SMCと`IOHIDEventSystem`を使い、取得した名前やキーをもとにCPU、GPU、SoC、バッテリーなどに分類します。分類は名前からの推定です。SMCから取得したセンサーには`CPU (SMC Tp01)`のように元のキーを表示し、物理コアの番号としては扱いません。メニューバーの数値も、CPU全体の平均温度ではありません。

温度表示の色は35℃で緑、55℃で黄緑、70℃でオレンジ、85℃で赤となり、その間はグラデーションで変化します。この色分けは表示上の目安です。CPUメーカーの温度上限や故障の判定基準を表すものではありません。

## センサーの確認とテスト

UIを開かず、取得できたセンサーを確認するには、リポジトリ内で次を実行します。

```bash
CPUTEMP_DUMP=1 swift run -c release
```

センサーが取れないときは、まずこの出力を確認してください。アプリから管理者権限を要求する処理はありませんが、すべての機種で温度を取得できることは保証していません。

```bash
swift test
```

テストでは、CPUセンサーがない場合、GPUの方が高温の場合、無効な測定値が含まれる場合の表示値の選択を確認します。実機のセンサーは使わないため、機種ごとの取得可否や測定値の精度を検証するものではありません。

`Sources/SMCSensors/`にはセンサーを読むCの処理、`Sources/CPUTemp/`にはSwiftで書いた分類処理と画面があります。

## 非公開インターフェイスについて

SMCと`IOHIDEventSystem`の名称や挙動は、将来のmacOSで変わる可能性があります。このアプリはソースからビルドして使うことを想定しています。
